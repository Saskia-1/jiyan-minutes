# 隐私、数据位置与清理边界

平台是本机单用户应用，但“本机”不等于“自动保密”。SQLite 默认没有数据库加密；本项目通过工作区外目录、文件 `0600`、目录 `0700`、回环监听、同源会话/CSRF 和秘密后端降低风险。若数据/导出目录位于 iCloud Drive、网盘同步目录、Time Machine 或其他备份范围，文件可能被同步或备份；项目不能替用户撤销这些副本。

## 保存的位置

- `platform.sqlite3`：来源公开配置、授权摘要、任务状态；不保存 Token/Key 或聊天正文。
- `platform.chat.sqlite3`：规范化消息、不可变快照、本地全文索引、生成结果、证据、文档版本、缓存和不含正文的 Provider 用量记录。默认未加密。
- 导入预览：用户选择的文件或粘贴文本先在进程内存中解析；预览缓存保留精确输入字节、计数和摘要，过期或提交后清理。提交时重新解析并核对，再保存规范消息、来源指纹与预览分析。聊天导入默认最多同时 8 个预览、原始输入合计 128 MiB；旧手动接口默认替换同一浏览器会话的上一个预览，主对话使用 `retain_pending` 保留仍待处理的多个预览，仍受总容量和时效限制。主对话对用户选好的有效内容直接提交，不再要求额外确认；无法确定的内容需先处理。
- `EXPORT_ROOT/exports/`：原子写入的 JSONL、文本和 manifest 导出批次。
- `EXPORT_ROOT/documents/`：本地 Markdown/DOCX 文档。
- macOS Keychain：QCE/TraceMemo API Token；浏览器只看到“已配置/未配置”。
- 进程环境：用户显式提供的 `DEEPSEEK_API_KEY`；不写入数据库或前端。

应用日志关闭 Uvicorn access log；错误响应不包含上游响应体、聊天正文、密钥或绝对路径。崩溃、系统交换文件、第三方工具日志和操作系统诊断仍可能有独立风险。

## 六个不同动作

1. **撤销一次性授权**：过期、消费或取消后不可重放；不删除已完成数据。
2. **断开来源**：忘记本平台的 QQ/微信连接配置、选择句柄和未用授权；要求先单独删除 Keychain Token。保留已导入快照、文档和文件。
3. **删除本项目数据**：先展示精确影响计数和指纹，再删除目标批次或文档及相关 SQLite 行、版本、衍生结果和缓存。
4. **删除受管文件**：删除计划中必须额外勾选；只处理该批次目录或已登记文档文件。未勾选时数据库可删除而文件保留，并明确提示不是取证擦除。
5. **清理第三方工具**：QCE/TraceMemo 的运行副本、数据库密钥、消息/媒体/更新/AI 缓存由对应工具管理；平台没有通用删除接口，也不会声称已经清理。
6. **撤销 macOS 权限**：完全磁盘访问、辅助功能、登录项等应由“系统设置”或工具自己的卸载流程处理；断开/删除项目数据不会撤销它们。

## 删除的一致性

删除先冻结影响图并生成短期指纹。若目标变化，确认失败。选择删除文件时，平台先把精确受管文件原子改名到同目录暂存，再提交数据库事务；数据库失败会恢复文件。若数据库已提交但清理中断，计划保持 `cleanup_pending`，下次启动重试已记录的暂存项。平台拒绝符号链接、路径穿越、意外目录项和未批准输出根。

删除不会向 QQ、微信、QCE、TraceMemo 或 DeepSeek 发送删除请求；也不会删除原始聊天。普通删除不能保证 SSD、备份或同步服务中的取证级擦除。

手动导入批次在当前 HttpOnly 本地浏览器会话中分页恢复；刷新或闲置后重新进入页面可在首次签发后的 7 天绝对窗口内续期短期活跃租约并刷新不透明会话句柄。超过绝对期限会换发新会话，旧 cookie 不能再次取得原批次权限；旧数据库迁移也不会延长原会话期限。页面为每个批次保留独立删除入口。清除浏览器会话 cookie 或超过绝对恢复窗口都会失去这条会话级恢复路径，因此应及时从“已导入批次”核对并删除不再需要的批次。

## DeepSeek 外发

只有 AI 整理步骤可能访问互联网。主对话按用户 2026-10-23 的明确要求简化：上传／粘贴同意本机导入，发送整理要求授权该轮自动使用所选资料，权限只绑定本轮、会话和原来源；停止、来源变化、新任务或重启撤销，浏览历史不会自动外发。高级手动工具仍显示完整脱敏请求并逐次确认。脱敏不能保证覆盖所有个人信息，附件、媒体、数据库、来源 Token 与 API Key 不外发。取消可能发生在供应商已收到请求之后，因此仍可能产生用量／费用。
