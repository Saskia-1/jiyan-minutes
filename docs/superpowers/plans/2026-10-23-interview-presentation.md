# 面试展示材料 Implementation Plan

**Goal:** 为记言提供自然、准确、能追溯到实现的 AI 产品岗位展示材料。

**Architecture:** README 承担入口；产品案例解释决策并链接实现和验收；演示说明配套合成输入。代码只在发现影响既有承诺的缺陷时修改。

**Tech Stack:** Markdown、Mermaid、已有 Python 解析器及测试。

**Spec:** [已确认方案](../specs/2026-10-23-interview-presentation-design.md)

## Global Constraints

只写用户确认的个人经历；不虚构效果数据。不更改 v10 总结方式，不运行真实模型，不接触用户聊天或密钥。保留无关未跟踪文件。用户已批准直接写作，无需再次询问执行方式。

## Review Focus

旧流程混入新主流程；把引用校验写成事实正确保证；把本地检索写成向量 RAG；把合成测试写成真实模型验收；把 AI 辅助实现写成独立手写代码。
