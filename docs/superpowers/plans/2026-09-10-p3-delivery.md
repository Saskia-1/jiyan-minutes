# P3 Documents, Cleanup, and Delivery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish local document versioning, DOCX/Markdown export, deletion/disconnection, recovery/security hardening, full documentation, and reproducible macOS delivery.

**Architecture:** Document versions remain append-only and distinguish model output from human edits. Local renderers consume validated structured versions without a model call; deletion uses an impact plan plus confirmation fingerprint and transactionally revokes/cancels dependents before optional managed-file removal.

**Tech Stack:** FastAPI, SQLite, python-docx, pytest; React, TypeScript, Vitest, Playwright.

**Spec:** `chat_to_howto_codex_prompt_v3.md`

## Global Constraints

- Editing, evidence viewing, and repeated DOCX/Markdown export make zero model calls.
- User edits never gain fabricated evidence and never overwrite source snapshots or prior versions.
- Disconnecting a source, deleting project data, deleting managed exports, clearing third-party caches, and revoking OS permissions are distinct actions.
- No delete endpoint is ever forwarded to QQ/WeChat, and ordinary deletion is not called forensic erasure.
- Generated filenames are safe; generated files are private, local, non-overwriting, and verified after writing.
