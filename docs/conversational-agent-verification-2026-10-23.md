## 保留边界与局限

名称和系统目录保持不变，生成仍使用 v10 总结方式。迁移 18 仅扩展本应用数据库，不访问微信或 QQ 数据库。会话用户消息及敏感运行上下文受原文 7 天清理约束，刷新不延长有效期；文档版本长期保留。参考下载每次重新获取当前有效的文档文字对，原文删除后不再从旧浏览器缓存提供摘录。

本轮测试使用合成资料与受控测试 Provider，测试服务禁止外连；没有发起真实模型请求，没有用模拟输出替代真实模型质量验收。未验证真实微信／QQ 导出或跨领域语义质量。费用无法可靠估算时明确显示不可估算。

沿用既有 512 字主题预算，连续要求累计超限会明确提示简化并新建对话，不静默丢弃约束。每次外发仍需用户在产品中授权，因此不会在没有授权的情况下连续调用模型。

仅同步项目代码、测试和文档；密钥、运行配置、本地数据库、真实资料及个人学习／调试文件不在提交范围。远端同步沿用用户已批准的 GitHub 官方 API，校验原始提交和文件树，仅快进、不删除分支或覆盖历史。

## 主输入框直接粘贴修复

用户反馈独立「粘贴笔记」编辑区导致聊天内容越界，覆盖下方已展开的高级工具。已删除该按钮与编辑区，主输入框直接本地识别带时间或说话人分隔的聊天，普通整理要求仍作为消息；无独立页面跳转。纯「说话人：正文」多方对话转换为既有块式解析格式，续行正文保留。任务字段如背景／约束／输入／输出等不按说话人处理。

识别到聊天只创建本地预览，导入及部分跳过仍需用户分别确认；超过 512 字的聊天先作为资料处理，不作为模型任务发送。切换会话后的晚预览不带入新会话。未解析成功的文字可在同一资料卡按普通文本预览，不恢复已撤下的独立笔记编辑器。

聊天容器补全网格与收缩边界，消息区独立滚动。浏览器覆盖桌面、360px、620／520px 高度、170px 主输入框、三份长聊天卡及展开高级工具，断言输入区不越界且页面无横向溢出。

同时修复连续预览覆盖旧预览的问题：对话导入显式使用 `retain_pending=true` 保留多份预览，仍计入原有数量／字节预算与过期清理；旧高级工具默认继续替换同会话旧预览。新增真实服务与 API 回归验证多份分别提交、严格布尔字段和容量上限。
