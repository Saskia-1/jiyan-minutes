# 用户操作与后台流程

> 阅读范围（2026-10-23）：本文按早期逐按钮流程描述后台能力，包括保留的高级手动工具和尚未开放的来源接入。当前主对话是「手选资料 → 发送要求 → 自动检索与整理 → 双 TXT」，不需要按下文逐次确认。当前 Agent 的工具选择、状态与边界见[产品案例](product-case-study.md#技术怎样承接产品规则)，实际演示见[演示说明](interview-demo.md)。

本文面向会基础编程、但不熟悉全部后端细节的使用者。

- **适配器**：把某个本地工具的固定只读接口转换成平台统一消息格式的代码层。
- **快照**：一次成功导入后冻结的消息集合；后续搜索和生成只引用该集合。
- **幂等**：同一个操作标识重复提交不会重复产生任务或数据。
- **Token**：证明有权调用某个来源/API 的秘密字符串；来源 Token 存在 macOS Keychain，浏览器不回显。
- **CSRF**：阻止别的网站借用本机浏览器身份调用本平台写接口的随机令牌。
- **半开时间范围**：包含开始时刻、不包含结束时刻的 `[start,end)`；避免相邻导出重复边界消息。
- **Provider**：实际执行 AI 生成的服务；生成核心只依赖通用 Provider 协议。当前生产适配器是 DeepSeek，自动测试使用不联网的 Fake/Deterministic Provider。

当前 Ultra Gate 1 结论会覆盖来源类按钮：QQ/QCE 与微信/TraceMemo 都显示 `blocked`；保存来源、保存/读取 Token、读取会话和新建来源导出在前端禁用，并由后端再次以 409 拒绝。删除 Token、断开来源仍可清理既有状态。下面第 2–5 节保留的是未来有新候选通过 Gate 后的逐按钮流程，不代表当前发布物已可操作。

每项都按相同七个字段说明；“重试重新开始”表示重新走该动作的验证/冻结步骤，不会偷偷扩大原范围。

## 0. 首次初始化

**用户动作 →** 运行 `scripts/bootstrap_macos.sh`，核对显示的数据/导出目录并输入 `YES`。  
**本平台后端接口 →** 此时不启动 HTTP；脚本创建 Python 环境、锁文件依赖、生产前端和私有非秘密配置。  
**本地源接口（如有）→** 无；不会安装或连接 QCE/TraceMemo。  
**数据读写 →** 在批准的工作区外目录写 `runtime-config.json`（0600）；已有文件不覆盖。源码数据和既有 SQLite 不删除。  
**是否调用外部模型/发送什么 →** 不调用。依赖安装可能连接包仓库，只发送普通包下载请求，不发送聊天或 Key。  
**返回结果 →** 可执行环境和启动命令。  
**常见失败/取消/重试/费用 →** 非 arm64 Mac、Python/Node 版本不符、网络或磁盘失败会停止；重跑保留配置并按锁文件校验。无模型费用。

## 1. 打开平台

**用户动作 →** 运行“启动”脚本并打开 `http://127.0.0.1:8765`。  
**本平台后端接口 →** 服务先迁移两个 SQLite、协调上次中断任务；浏览器加载静态文件后请求 `GET /api/session`、环境和来源状态。业务 API 校验严格 Host/Origin、会话 Cookie 和 CSRF。  
**本地源接口（如有）→** 无；打开页面不会连接聊天工具。  
**数据读写 →** 会话只以摘要保存；迁移追加 schema，不重建已有数据。  
**是否调用外部模型/发送什么 →** 不调用、不外发。  
**返回结果 →** 本机版本、安全状态和两个来源的独立状态。  
**常见失败/取消/重试/费用 →** 配置权限、端口占用、构建缺失会停止；修复后重新启动。无费用。

## 2. 连接数据源

**用户动作 →** 选择 QQ/微信，填写账号标识与实际客户端/工具/账号数据版本，点击“保存本机来源配置”；如工具需要 Token，再走“查看令牌保存确认”与“保存 Token”。  
**本平台后端接口 →** `POST /api/sources` 保存公开绑定；`POST /api/sources/{id}/secret-consents` 生成一次性确认，`.../secret-operations` 在确认后执行 `secret_set`。  
**本地源接口（如有）→** 保存配置阶段不调用来源；Token 通过 macOS `security` 标准输入进入 Keychain。  
**数据读写 →** SQLite 保存版本、固定回环端点、随机配置 nonce 与秘密引用，不保存 Token。  
**是否调用外部模型/发送什么 →** 不调用。Token 不发给 DeepSeek。  
**返回结果 →** `needs_user_action` 或已配置秘密状态，绝不因文档自动显示 ready。  
**常见失败/取消/重试/费用 →** 端点/字段不符、Keychain 拒绝或确认过期则无连接；重新查看确认后重试。无费用。

## 3. 选择聊天

**用户动作 →** 点击“读取本机会话列表”，再勾选一个或多个不透明会话选项。  
**本平台后端接口 →** `GET /api/sources/{id}/conversations` 要求活会话和一次 `secret_get` 授权，校验当前版本/账号/nonce。  
**本地源接口（如有）→** QQ 只调用 QCE friends/groups/recent-contacts；微信只调用 TraceMemo contact。此步只取显示名、类型和稳定 ID，不取正文。  
**数据读写 →** 浏览器只拿短期不透明选择句柄；真实会话 ID 留在后端选择表，到期或配置变化失效。  
**是否调用外部模型/发送什么 →** 不调用、不外发。  
**返回结果 →** 可区分重名会话的列表。  
**常见失败/取消/重试/费用 →** 工具未就绪、Token/版本变化或列表过大则失败且不读取正文；重新授权后从头列举。无费用。

## 4. 选择时间

**用户动作 →** 编辑开始、结束和显示时区；结束不包含。  
**本平台后端接口 →** 前端先拒绝空值/倒序；生成确认时后端把带时区值规范化为 UTC 和毫秒。  
**本地源接口（如有）→** 尚不调用。  
**数据读写 →** 仅页面状态；确认后范围会进入指纹和任务冻结副本。  
**是否调用外部模型/发送什么 →** 不调用。  
**返回结果 →** 可确认的半开窄范围。  
**常见失败/取消/重试/费用 →** 无时区、结束不晚于开始或句柄过期时按钮禁用；修正后重试。无费用。

## 5. 导出聊天到本地

**用户动作 →** 勾选“确认只导出所选会话和时间范围”，点击“导出并建立本地索引”。  
**本平台后端接口 →** `POST /api/export-jobs/consents/from-selections` 冻结范围并签发一次性授权；`POST /api/export-jobs` 用幂等键建任务，状态依次为授权、连接、读取、保存、校验、导入/完成。  
**本地源接口（如有）→** 适配器只用允许的消息读取路由；每个返回再次按会话和 `[start,end)` 过滤。  
**数据读写 →** `EXPORT_ROOT/exports/<batch>/` 中原子写 JSONL、文本、manifest，计算计数和 SHA-256，拒绝路径穿越/符号链接/覆盖。  
**是否调用外部模型/发送什么 →** 不调用 DeepSeek。来源流量只到固定本机回环端口。  
**返回结果 →** 真实文件存在且验证后才进入可导入状态；完整性为 complete/partial/unknown 的实际证据。  
**常见失败/取消/重试/费用 →** 来源、分页、空间、权限、写入或哈希失败不伪成功；取消阻止后续步骤但不能撤销已发出的同步来源请求。重试重新读取冻结范围。无模型费用。

## 6. 自动导入

**用户动作 →** 不需第二个按钮；成功导出自动继续。  
**本平台后端接口 →** 同一导出任务调用 BatchImporter，随后创建不可变快照和索引。  
**本地源接口（如有）→** 无第二次来源读取。  
**数据读写 →** 逐行解析已验证 JSONL，以来源消息 ID 或确定性后备 ID 幂等入库；建立批次成员、快照成员和 FTS 搜索索引。  
**是否调用外部模型/发送什么 →** 不调用、不外发。  
**返回结果 →** `complete + searchable=true` 和 batch/snapshot 标识。  
**常见失败/取消/重试/费用 →** 损坏、超大输入、事务/索引失败保留可诊断任务，不把半成品标成可搜索；重试导入必须重新校验文件。无费用。

## 6A. 文件或粘贴导入

**用户动作 →** 选择 TXT/JSON/JSONL/CSV/XLSX/受支持单文件 ZIP 或粘贴明确支持的聊天文本，选择时区、默认日期/会话和必要的列映射，点“生成导入预览”；核对后再勾选并确认。刷新后可从“已导入批次”分页恢复、打开或逐批删除。  
**本平台后端接口 →** `POST /api/imports/previews` 只在内存中解析；`POST /api/imports/previews/{id}/commit` 核对会话、过期时间和预览指纹后原子创建 batch/snapshot；`POST /api/imports/recovery` 只在当前 HttpOnly 本地会话的 7 天绝对恢复窗口内恢复其批次，刷新短期选择句柄并保留提交时区。  
**本地源接口（如有）→** 无；不连接 QCE/TraceMemo，不读取 QQ/微信数据库。  
**数据读写 →** 预览前不写数据库；确认后写入来源指纹、规范消息、密封快照和短期不透明会话句柄。  
**是否调用外部模型/发送什么 →** 不调用、不外发；后续仍必须单独查看 AI 外发预览并确认。  
**返回结果 →** 可见的解析计数、未解析原因、warning、样例与绑定具体 snapshot 的可搜索导入会话。  
**常见失败/取消/重试/费用 →** 空/超限/编码错误、不支持格式、损坏 XLSX/ZIP、缺列、时间或会话不明时停止提交，并给出不含正文的恢复建议；修正设置后重新预览。无模型费用。

## 7. 输入话题

**用户动作 →** 在“操作主题”输入要整理的目标。  
**本平台后端接口 →** 尚不请求；点击预览时进入 `/api/generation/previews/from-selections`。  
**本地源接口（如有）→** 无。  
**数据读写 →** 页面状态；预览时主题进入冻结范围和指纹。  
**是否调用外部模型/发送什么 →** 输入过程中不调用。  
**返回结果 →** 可供快速/完整筛选的主题。  
**常见失败/取消/重试/费用 →** 空主题或范围无效不能预览；修改后重新预览。无费用。

## 8. 查看命中

**用户动作 →** 在“搜索聊天内容”输入关键词并点“搜索本地聊天”；可将不应进入下一次 AI 生成的命中勾选为“不用于 AI 生成”。  
**本平台后端接口 →** `POST /api/search/from-selections` 把不透明句柄解析为真实会话 ID，调用当前快照限定的 SearchService。  
**本地源接口（如有）→** 无；搜索不再访问 QQ/微信工具。  
**数据读写 →** 只读本地 SQLite FTS 和快照成员表，保存不含正文的搜索运行元数据。  
**是否调用外部模型/发送什么 →** 不调用、不外发。  
**返回结果 →** 按相关性/时间稳定排序的命中、发送者、时间、会话、批次和快照；生成区同步显示排除条数。  
**常见失败/取消/重试/费用 →** 快照/句柄/时间不匹配返回空或错误；新搜索、会话或时间范围变化会清除排除项和旧外发授权。缩小范围可重搜，扩大范围需重新导出。无费用。

## 9. 完整筛选

**用户动作 →** 选择“完整范围”或“主题字面匹配（快速）”，点击“预览 AI 外发”。  
**本平台后端接口 →** GenerationScopeBuilder 从快照选取消息，应用排除项、时间/会话/主题规则和消息/token/调用预算，再按消息边界分块。  
**本地源接口（如有）→** 无。  
**数据读写 →** 只读快照；保存短期预览、范围指纹、缓存身份和预算，不保存额外明文副本。  
**是否调用外部模型/发送什么 →** 仍不调用。  
**返回结果 →** 精确消息数、字符数、预计 token、最多调用数、缓存状态和完整脱敏外发文本。  
**常见失败/取消/重试/费用 →** 超预算、无证据、非法排除项或快照不属于会话时失败；调整本地范围后重新预览。无费用。

## 10. 外发确认

**用户动作 →** 展开查看每个完整脱敏分块，勾选“授权本次向外部 AI 发送”，点击“确认并生成”。  
**本平台后端接口 →** `POST /api/generation/consents` 校验预览未过期且会话/正文 SHA/范围指纹未变；签发一次性授权。  
**本地源接口（如有）→** 无。  
**数据读写 →** 保存授权摘要、过期时间和已用状态，不保存 DeepSeek Key。  
**是否调用外部模型/发送什么 →** 签发授权本身不外发；下一步只会发送屏幕所示 user JSON 文本和固定系统提示。  
**返回结果 →** 可启动一次生成任务。  
**常见失败/取消/重试/费用 →** 未勾选、过期、范围变化、跨会话或重放立即拒绝；重新预览。此步无费用。

## 11. 生成

**用户动作 →** 上一步确认后等待任务，或对明确失败任务点击重试/取消。  
**本平台后端接口 →** `POST /api/generation/jobs` 建幂等任务；先查本地缓存，再为每个分块创建不含正文的请求用量记录，调用 DeepSeek Chat Completions，随后提取、合并。  
**本地源接口（如有）→** 无。  
**数据读写 →** 保存状态事件、Provider 请求 ID/可用 token 计数、结构化结果；缓存身份绑定快照、范围、模型、提示/Schema/分块/脱敏版本。  
**是否调用外部模型/发送什么 →** 缓存未命中时 HTTPS 发往固定 DeepSeek 域名；发送固定系统提示和预览中完整展示的脱敏 user 文本，不发送附件/数据库/Token/Key。  
**返回结果 →** 完整、失败或取消状态；缓存命中为零请求。  
**常见失败/取消/重试/费用 →** 认证、额度、限流、超时、空/截断/JSON错误、每日上限分别失败。取消/超时后 Provider 可能已收到请求并计费；重试从冻结范围重新开始并累计请求记录。

## 12. 结果校验

**用户动作 →** 无额外按钮；生成返回后自动执行。  
**本平台后端接口 →** Pydantic 严格校验 JSON；Merge 去重保留冲突；EvidenceValidator 重新从本地快照派生允许文本，验证每个消息 ID、完整引用和范围。  
**本地源接口（如有）→** 无。  
**数据读写 →** 只把通过证据校验的结果标成 `verified` 并缓存；失败结果不伪装成指南。  
**是否调用外部模型/发送什么 →** 校验完全本地，不二次调用。  
**返回结果 →** 已验证操作指南、证据不足，或稳定错误码。  
**常见失败/取消/重试/费用 →** 伪造/越界/改写引用、提示注入诱导出的额外字段都被拒绝；可显式重试，但先前外部调用可能已有费用。

## 13. 查看依据

**用户动作 →** 展开“查看已验证证据”。  
**本平台后端接口 →** 已完成任务响应或文档读取返回经过授权的本地 evidence。  
**本地源接口（如有）→** 无。  
**数据读写 →** 只读当前会话拥有的快照/生成记录；不会执行消息里的 URL、命令或提示。  
**是否调用外部模型/发送什么 →** 不调用、不外发。  
**返回结果 →** 发送者、时间、会话、消息标识和原始本地引文。  
**常见失败/取消/重试/费用 →** 跨会话/已删除对象拒绝；刷新或回到仍存在的任务。无费用。

## 14. 编辑

**用户动作 →** “创建可编辑文档”，修改标题/步骤和说明，点击“保存为新版本”；也可从旧版本创建恢复版本。  
**本平台后端接口 →** `POST /api/documents/from-generation`、`POST /api/documents/{id}/versions` 或 `.../restore`；要求生成已验证、属于当前会话、父版本仍是当前版本。  
**本地源接口（如有）→** 无。  
**数据读写 →** 追加不可变版本，不覆盖 AI 原始版本；用户编辑/恢复标为 `unverified`，不得引用快照外证据。  
**是否调用外部模型/发送什么 →** 零模型调用。  
**返回结果 →** 当前版本和完整历史。  
**常见失败/取消/重试/费用 →** 并发父版本变化、内容过大/控制字符/越界证据会拒绝；重新读取后人工合并。无费用。

## 15. 导出 Word

**用户动作 →** 选择 DOCX（或 Markdown）、“仅指南正文/指南与来源证据”，点击“导出当前版本”。  
**本平台后端接口 →** `POST /api/documents/{id}/exports` 读取指定不可变版本，用 python-docx 或 UTF-8 Markdown 本地渲染。  
**本地源接口（如有）→** 无。  
**数据读写 →** 在批准目录 `documents/` 原子写入安全中文文件名，拒绝覆盖并回读字节校验，保存大小和 SHA-256。  
**是否调用外部模型/发送什么 →** 零模型调用，不外发。  
**返回结果 →** 文件名、格式、大小、哈希和创建时间；不会向浏览器暴露绝对路径。  
**常见失败/取消/重试/费用 →** 目录变化、空间/权限、符号链接、碰撞或回读失败会清理临时文件；重试产生新安全文件名。无费用。

## 16. 删除

**用户动作 →** 在批次或文档下选择是否同时删除受管文件，点击“查看删除影响”，核对计数/效果/指纹，再勾选并“确认删除”。  
**本平台后端接口 →** `POST /api/deletion-plans` 冻结依赖图；`POST /api/deletion-plans/{id}/confirm` 再算指纹、暂存文件、提交数据库事务、清理暂存。  
**本地源接口（如有）→** 无删除/写请求；绝不删除 QQ/微信原始聊天。  
**数据读写 →** 可删除目标文档/版本/导出记录/生成任务与请求记录/授权/缓存，或批次/快照/索引/无其他引用消息；文件必须单独勾选。  
**是否调用外部模型/发送什么 →** 不调用、不外发。  
**返回结果 →** 精确删除计数、complete 或 cleanup_pending；未选文件时明确 retained。  
**常见失败/取消/重试/费用 →** 未确认、过期、依赖变化、意外文件/符号链接则不执行或恢复暂存；崩溃后启动协调仅重试已记录清理。无新费用，历史 Provider 费用不会被撤销。

## 17. 断开数据源

**用户动作 →** 先用独立确认删除已保存 Token，再点“准备断开本机来源”，阅读差异、勾选并确认。  
**本平台后端接口 →** `POST /api/sources/{id}/secret-operations` 执行 Keychain `secret_delete`；`POST /api/sources/{id}/disconnect` 只在无秘密、无活动 P0/P1/P2 任务时清除本地连接授权。  
**本地源接口（如有）→** 不联系 QCE/TraceMemo，不调用退出、卸载、缓存删除或权限接口。  
**数据读写 →** 删除本平台来源公开配置、选择句柄、挑战和未用 grant；已导入快照、文档、文件保留。  
**是否调用外部模型/发送什么 →** 不调用、不外发。  
**返回结果 →** 来源回到 unconfigured，历史本地内容仍可按现有授权查看。  
**常见失败/取消/重试/费用 →** Token 仍存在或任务活动时拒绝；先完成/取消相关任务再重新准备。无费用。

## 首次初始化与断开的区别

初始化是在任何业务读取前创建运行环境、空数据库和批准目录；它不连接来源。断开只撤销某一个已配置来源的本平台连接能力；它不是卸载、数据删除、第三方缓存清理或 macOS 权限撤销。若要删除本地批次/文档，必须另走第 16 项的影响预览和确认。
